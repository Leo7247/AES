Cryptographic Integrity & Architecture

AES-256-GCM Mode Galois/Counter Mode provides both confidentiality and built-in cryptographic authentication to prevent bit-flipping attacks.
Dynamic 96-Bit Nonce Every encryption run generates a fresh cryptographically strong pseudo-random initialization vector (IV).
Immured Key Architecture The pre-shared key is non-extractable from the UI, preventing accidental exposure or manual tampering.

GhostCipher Help & Security Guide

1. Text Encryption

Enter secret text in Encrypt Message, click Encrypt, then use Copy Encrypted Text to distribute the Base64 output.

2. Text Decryption

Open Decrypt Message and click Paste Encrypted Messages. The payload will authenticate and restore the original plaintext.

3. File Vault Encryption

Switch to File Vault in Encrypt mode. Drop any document, image, or zip file. The app packages the filename, mime type, and bytes into a secure encrypted .enc file.

4. File Restoration

Switch to File Vault in Decrypt mode. Drop the .enc envelope. The key authenticates the GCM tag, restores the exact filename, and downloads the original file.

Protocol Specifications & Privacy

Tamper-Proof Galois/Counter Mode: AES-GCM calculates a 128-bit authentication tag. If any byte is altered in text or file payloads, decryption fails immediately.

100% In-Memory Processing: Plaintext and decrypted files never touch any external server. Everything is processed directly in browser RAM via the W3C Web Crypto API.

Binary Header Structure: File packages begin with a 4-byte magic signature GC01, metadata length header, encrypted JSON metadata (name, type, timestamp), and raw ciphertext.

Troubleshooting & Tips

If you see "Authentication Failed / Corrupt Payload", ensure that the file is an intact .enc envelope created with this engine and not truncated during transmission.
