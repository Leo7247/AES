Cryptographic Integrity & Architecture

AES-256-GCM Mode Galois/Counter Mode provides both confidentiality and built-in cryptographic authentication to prevent bit-flipping attacks.
Dynamic 96-Bit Nonce Every encryption run generates a fresh cryptographically strong pseudo-random initialization vector (IV).
Immured Key Architecture The pre-shared key is non-extractable from the UI, preventing accidental exposure or manual tampering.

GhostCipher Help & Security Guide

1. How to Encrypt

Select Encrypt Message tab, enter your confidential text in the raw message box, and click Encrypt. Click Copy Encrypted Text to share the Base64 ciphertext with anyone using this cipher link.

2. How to Decrypt

Select Decrypt Message tab. Click Paste Encrypted Messages (or press Ctrl+V). The cipher will automatically authenticate and decipher the text into original plaintext.

Protocol Specifications & Privacy

Tamper-Proof Galois/Counter Mode: AES-GCM includes a 128-bit authentication tag. If any byte in the transmission is modified or truncated, decryption fails immediately.

Zero Server Exposure: All cryptographic operations execute 100% locally in your browser via the native W3C Web Crypto API. No data, plaintext, or cipher is sent to any server.

Why is the key hidden & locked? This application operates on an embedded pre-shared pairing model. Both parties communicate over the pre-agreed channel without exchanging passwords across untrusted networks.

Troubleshooting & Tips

If you see "Authentication Failed / Corrupt Payload", ensure that the entire Base64 string was copied without missing characters or extra spaces.
